# ShareCom 설계

같은 와이파이에 있는 Windows PC 2~4대를 마우스·키보드 하나로 함께 조작하고, 클립보드와 파일을 주고받는 프로그램이다. 이 문서는 2026-11-05 설계 인터뷰에서 합의한 내용이다.

## 1. 범위

- 사용자 한 명이 자기 PC 2~4대에서만 쓴다. 공개 배포, 코드 서명, 설치기는 하지 않는다.
- 어느 PC든 주인이 될 수 있다. 마우스를 실제로 움직인 PC가 그때의 주인이다.
- 화면 글자는 한국어만 쓴다.

## 2. 기술

- C# / .NET 10 (LTS, 2028-11 까지 지원), WinForms.
  - 처음에는 .NET 8 로 정했다가 바꿨다. .NET 8 은 2026-11-10 에 지원이 끝나기 때문이다.
- 배포는 런타임을 포함한 단일 파일 `ShareCom.exe` 이다(self-contained, single-file).
- 관리자 권한으로 실행한다(`requireAdministrator` 매니페스트).
  - 관리자 권한 창(작업 관리자 등)까지 조작할 수 있다.
  - UAC 창과 잠금 화면은 Windows 보안 데스크톱이라 조작할 수 없다. 해당 PC의 마우스·키보드로 직접 처리한다.
- 첫 실행 때 이 exe 를 허용하는 인바운드 방화벽 규칙을 자동으로 추가한다.
- 모니터별 DPI 인식(PerMonitorV2)을 켜서 좌표를 실제 픽셀로 다룬다.

### 프로젝트 구성

| 프로젝트 | 대상 | 역할 |
|---|---|---|
| `src/ShareCom.Core` | `net10.0` | 프로토콜, 연결·짝 맺기·재연결, 화면 경계 계산. Windows API 를 쓰지 않아 자동 시험이 가능하다. |
| `src/ShareCom.App` | `net10.0-windows` | 트레이 UI, 입력 훅, 입력 재현, 클립보드, 방화벽, 신원 저장. |
| `tests/ShareCom.Core.Tests` | `net10.0` | xUnit 자동 시험. 한 PC 안에서 노드 두 개를 띄워 통신을 시험한다. |

## 3. 기능

### 3.1 마우스·키보드 넘기기

- 마우스와 키보드가 함께 넘어간다. Ctrl+Alt+Del 은 Windows 가 막아서 넘어가지 않는다.
- 화면 가장자리로 밀면 이웃 PC로 넘어간다.
- 단축키

  | 단축키(기본값) | 동작 | 설정에서 고를 수 있는 값 |
  |---|---|---|
  | `Scroll Lock` | 가장자리 넘기기 잠금 켜기/끄기 | `Scroll Lock`, `Pause`, 쓰지 않음 |
  | `Ctrl+Alt+1~4` | 해당 번호 PC로 바로 이동(1 = 내 PC) | 수정키 `Ctrl+Alt`, `Ctrl+Shift`, `Ctrl+Alt+Shift`, 쓰지 않음 |
  | `Ctrl+Alt+Esc` | 긴급 복귀. 무조건 내 PC로 돌아온다. | 바꿀 수 없다(안전장치) |

  - 바로 이동은 고른 수정키가 정확히 눌렸을 때만 먹는다(`Ctrl+Shift` 를 골랐으면 `Ctrl+Alt+Shift+2` 는 그대로 앱에 간다).
  - 고를 수 있는 값을 목록으로 정해 둔 것은 다른 프로그램 단축키와 부딪히지 않게 하려는 것이다(예: `Ctrl+Shift+Esc` 는 작업 관리자, `Alt+Shift` 는 입력 언어 전환이라 뺐다).

- 안전장치
  - 연결이 끊기면 입력이 곧바로 내 PC로 돌아온다.
  - 눌린 채 남은 키와 버튼은 양쪽에서 모두 떼어 준다.
  - 조작당하는 PC에서 그 PC의 실제 마우스·키보드를 쓰면 그 PC가 주인을 되찾는다.
- 조작이 끝난 PC의 포인터는 숨긴다.
  - 포인터는 마지막으로 받은 자리에 남는데, 빠르게 넘어가면 화면 안쪽에 떠 있게 된다.
  - 그 PC의 실제 마우스를 움직이거나 누르거나 휠을 굴리면 다시 보인다. 다시 조작당하기 시작할 때, 화면을 잠그거나 절전할 때도 다시 보인다.
  - 키보드만 쓸 때는 숨긴 채로 둔다(Windows 의 "입력하는 동안 포인터 숨기기"와 같다).
- 화면 배치 (4단계)
  - 모든 PC를 하나의 평면에 놓는다. 평면의 1칸은 "실제 픽셀 × 100 ÷ 그 PC 주 모니터 배율"이라, 배율이 다른 PC도 실제 크기 비율로 놓인다.
  - 트레이 메뉴 [화면 배치…]에서 PC 상자를 끌어 놓는다. 놓으면 가장 가까운 다른 PC 가장자리에 붙고, 끝이 가까우면 끝을 맞춘다. 겹치게는 놓을 수 없다.
  - 마우스를 밀었을 때 그 방향으로 맞닿은(4칸 안) 연결된 PC 모니터가 있으면 넘어간다. 원격 PC에서 또 다른 원격 PC로도 바로 넘어간다.
    - 맞닿은 구간 밖에서 밀면 가장 가까운 구간 끝으로 넘어간다.
    - 내 PC 안 모니터끼리 이어진 가장자리는 Windows 가 그대로 처리한다.
    - 모서리 10픽셀은 넘어가지 않는다(좌우로 밀 때는 위아래 모서리, 위아래로 밀 때는 좌우 모서리).
  - `Ctrl+Alt+숫자` 번호는 1 = 내 PC, 2번부터 배치에서 왼쪽부터(같으면 위부터) 매긴다. 연결되지 않은 PC도 번호를 차지해, 켜고 끌 때 번호가 바뀌지 않는다. 편집기 상자에 번호가 보인다.
  - 배치 동기화: 배치는 판 번호가 붙은 문서 하나다.
    - 판 번호가 크면 이긴다. 같으면 마지막으로 고친 PC의 ID 가 큰 쪽이 이긴다.
    - 각 PC는 자기 항목(이름·모니터·배율)만 넣고 고친다. 처음 들어갈 때는 짝 맺을 때 정한 쪽(없으면 맨 오른쪽 PC 옆)에 자동으로 놓인다.
    - 연결되면 서로 문서를 주고받고, 더 새 판을 받으면 다른 PC들에 다시 전한다. 짝 푼 PC 항목은 지운다.
    - 마지막 판을 `settings.json` 에 저장해 재시작해도 이어진다.

### 3.2 클립보드 (2단계)

- 텍스트, 서식 있는 글(HTML·RTF), 이미지를 자동으로 공유한다. 크기 제한은 없다.
- 한쪽에서 복사하면 다른 PC들의 클립보드에 바로 들어간다.

### 3.3 파일 (3단계)

- **복사/붙여넣기**: 탐색기에서 Ctrl+C 하면 파일 목록만 다른 PC로 넘어간다.
  - 그 PC의 탐색기에서 Ctrl+V 하는 순간 내용을 받는다. 탐색기가 붙여넣을 때 내용을 요청하는 가상 파일(`FileGroupDescriptorW` + `FileContents`) 방식이다.
  - 진행률은 탐색기 자체 창에 뜬다. 원본 PC가 켜져 있어야 한다.
- **트레이로 보내기**: 트레이 메뉴 [파일 보내기 → PC 이름 → 파일 고르기/폴더 고르기]로 특정 PC에 보낸다.
  - Windows 트레이 아이콘은 끌어다 놓기를 받을 수 없어 메뉴로만 보낸다(2026-11-05 결정).
  - 받는 PC에 받기/거절 창이 뜬다. 시간 제한은 없다.
  - 받으면 `다운로드\shareCom` 에 저장한다. 같은 이름이 있으면 `이름 (2)` 로 저장한다.

### 3.4 연결·보안

- **검색**: UDP 브로드캐스트로 같은 망의 PC를 자동으로 찾는다. 2초마다 알리고 마지막 주소를 기억해 둔다.
- **짝 맺기**: 처음 한 번만 한다.
  1. 한쪽에서 상대를 고르면 두 PC 화면에 같은 6자리 코드가 뜬다.
  2. 양쪽에서 코드가 같은지 확인하고 [짝 맺기]를 누른다.
  3. 이후에는 짝 맺은 PC만 연결을 허용한다.
  - 코드는 두 PC 인증서 지문을 해시해 만든다(숫자 비교 방식). 중간에 끼어든 기기가 있으면 코드가 달라진다.
  - 같은 망의 누구나 짝 맺기 요청을 보낼 수 있으므로, 들어오는 요청은 한 번에 하나만 받는다. 거절·실패·시간 초과로 끝난 주소의 요청은 30초 동안 확인 창 없이 무시한다(기록에는 남긴다).
- **자동 소개 (4단계)**: 3대 이상이면 새 PC는 이미 짝인 PC 하나와만 짝을 맺으면 된다.
  - 짝을 맺은 PC가 연결된 다른 PC들에 새 PC 인증서를 전하고, 받은 PC들도 그 PC를 신뢰한다. 반대로 기존 PC들 목록도 새 PC에 전한다.
  - 소개는 이미 짝인(인증된 연결의) PC가 보낸 것만 받는다.
  - [짝 풀기]도 모든 PC로 퍼진다. 짝 푼 PC는 철회 목록에 남겨, 다른 PC의 소개로 되살아나지 않게 한다.
  - 소개와 짝 풀기가 엇갈리면 시각이 늦은 쪽이 이긴다. 짝 푼 PC와 직접 다시 짝을 맺으면 그 시각이 더 늦으므로 다시 신뢰가 퍼진다.
- **신원**: PC마다 바뀌지 않는 고유 ID 와 ECDSA P-256 자체 서명 인증서를 가진다. 짝 맺기 때 상대 인증서 지문을 저장한다.
- **암호화**: 기본은 켬(TLS, 상대 인증서 지문 고정). 설정에서 끌 수 있다.
  - 두 PC 중 한쪽이라도 켜 두면 암호화한다.
    - 연결 머리말의 모드 바이트는 보호되지 않아 중간에서 바꿀 수 있다. 그래서 암호화를 요청한 쪽은 평문(또는 요청과 다른 모드) 응답을 받으면 신원 정보도 보내지 않고 끊는다. 평문을 요청했는데 상대가 암호화를 고르는 것만 허용한다.
  - 끈 경우에도 연결할 때 인증서 키 서명으로 상대를 확인한다. 내용은 평문으로 오간다.
    - 평문 연결은 위조 검사가 없어, 중간에 끼어든 기기가 엿볼 뿐 아니라 가짜 키 입력·마우스 조작을 넣을 수도 있다. 받는 쪽은 관리자 권한이므로 사실상 PC를 넘겨주는 것과 같다. 끌 때 이 내용을 경고한다.

### 3.5 자동 재연결

- 고유 ID 로 상대를 알아보므로 재부팅 뒤 IP 가 바뀌어도 다시 짝 맺지 않고 붙는다.
- 끊긴 상대에게 몇 초 간격으로 다시 연결을 시도한다. 절전에서 깨어났을 때, 와이파이가 잠깐 끊겼을 때도 같다.
- 2초마다 생존 신호(Ping)를 보내고, 6초 동안 응답이 없으면 끊긴 것으로 본다.
- 양쪽이 동시에 연결하면 ID 가 작은 쪽이 건 연결만 남긴다.
- 다시 붙으면 배치와 설정은 그대로 이어진다.
- 재부팅한 PC는 로그인하면 붙는다. 로그인 화면에서는 붙지 않는다(서비스를 두지 않기로 함). 손대지 않고 붙게 하려면 Windows 자동 로그인을 켠다.

### 3.6 실행 형태 (5단계)

- 트레이에 상주한다.
- 작업 스케줄러에 '가장 높은 권한'으로 등록해 로그인할 때 UAC 창 없이 자동으로 시작한다.
  - 처음 실행할 때 한 번 "자동으로 켤까요?" 묻는다. 이후에는 트레이 메뉴 [설정…]에서 켜고 끈다.
  - 작업 이름은 `ShareCom (사용자 이름)` 이다. 사용자마다 따로 등록한다.
  - 노트북 배터리에서도 켜지고, 실행 시간 제한이 없고, 보통 우선순위로 돈다(작업 스케줄러 기본값은 '낮음'이라 입력 훅이 늦을 수 있다).
  - 로그인 3초 뒤 `--autostart` 인자로 켠다. 이때는 "실행 중입니다" 알림을 띄우지 않는다.
  - 등록한 exe 경로를 기억해 두고, exe 를 옮겨 실행하면 새 경로로 다시 등록한다.
- 설정 창(트레이 메뉴 [설정…]): 자동 시작, 클립보드 공유, 암호화, 가장자리 넘기기 잠금, 단축키, 이 PC 정보(이름·지문·버전), 기록 폴더 열기.
  - 자주 쓰는 클립보드 공유·넘기기 잠금은 트레이 메뉴에도 그대로 둔다. 암호화는 설정 창으로만 옮겼다.
- 설정과 신원은 `%APPDATA%\ShareCom\` 에 둔다. 개인 키는 DPAPI 로 보호한다.

## 4. 통신 프로토콜

- 짝 하나에 TCP 연결 하나를 쓴다. 포트는 TCP 47821, UDP 검색 47820 이다.
- 연결 머리말: 매직 `SHCM` + 버전(1바이트) + 모드(1바이트). 모드 값은 `T`(TLS), `P`(평문), `R`(짝 맺기 요청)이다.
  - 서버는 실제로 쓸 모드를 돌려준다.
- 그다음 메시지 틀: `[u32 길이][u8 종류][본문]`.
- 주인 PC가 상대 화면 안의 가상 커서 위치를 직접 계산해 절대 좌표로 보낸다.
  - 가장자리 판정과 복귀 판정은 모두 주인 PC가 한다.
  - 상대 PC는 받은 좌표대로 `SendInput` 으로 재현만 한다.
- 키는 스캔 코드로 보낸다. 자판 배치와 관계없이 같은 물리 키가 눌린다.
- 버전 2(4단계)부터 배치 문서(`Layout`)와 신뢰 목록(`Trust`) 메시지가 있다. 버전 1의 화면 정보·좌우 메시지는 없앴으므로 모든 PC를 함께 올려야 한다.

## 5. 만드는 순서

각 단계는 쓸 수 있는 상태로 끝내고, 브랜치 → PR → merge 로 GitHub 비공개 저장소 `shareCom` 에 쌓는다.

1. 검색·짝 맺기·암호화·자동 재연결, 2대 마우스·키보드 넘기기(배치는 좌우 고정)
2. 클립보드
3. 파일 전송
4. 배치 편집기, 모니터 여러 대, 최대 4대
5. 자동 시작, 설정 화면 마무리

## 6. 시험

- 통신·짝 맺기·재연결·경계 계산·클립보드·파일 전송은 이 PC에서 노드 두 개를 띄워 자동으로 시험한다.
- 마우스·키보드 넘기기는 단계마다 사용자가 다른 PC에 exe 를 복사해 직접 확인한다. 확인할 목록은 `docs/manual-test.md` 에 둔다.
