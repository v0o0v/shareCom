# 실기 확인 목록

자동 시험으로 확인할 수 없는 부분(실제 마우스·키보드, 두 PC 사이 와이파이)을 사람이 직접 확인하는 목록이다. 단계마다 해당 절을 채운다.

## 준비

1. 이 PC에서 배포용 exe 를 만든다.

   ```bash
   dotnet publish src/ShareCom.App -c Release -o publish
   ```

2. `publish\ShareCom.exe` 를 두 PC에 복사한다(USB, 공유 폴더 등). 폴더 위치는 어디든 된다.
3. 두 PC에서 각각 `ShareCom.exe` 를 실행한다. UAC 창에서 [예]를 누른다.
   - Windows SmartScreen 이 "알 수 없는 게시자"라며 막으면 [추가 정보] → [실행]을 누른다(서명하지 않은 exe 라서 뜬다).
4. 작업 표시줄 오른쪽 트레이에 모니터 두 대 모양 아이콘이 생긴다. 회색은 연결 없음, 초록은 연결됨, 파랑은 다른 PC를 조작 중이다.

문제가 생기면 트레이 메뉴 [기록 폴더 열기]의 `log.txt` 를 보거나 그대로 전달한다.

## 1단계: 연결·짝 맺기·마우스·키보드

### 짝 맺기

| # | 할 일 | 기대 결과 | 결과 |
|---|---|---|---|
| 1-1 | PC A 트레이 아이콘 클릭 → [새 PC와 짝 맺기] | 몇 초 안에 PC B 이름과 IP 가 목록에 뜬다 | |
| 1-2 | PC B 이름 클릭 | 두 PC 화면에 같은 6자리 코드 창이 뜬다 | |
| 1-3 | 한쪽에서 [취소] | 양쪽 창이 모두 닫히고 짝이 맺어지지 않는다 | |
| 1-4 | 다시 요청해 양쪽에서 [짝 맺기] | "짝을 맺었습니다" → 몇 초 안에 "연결됐습니다", 아이콘이 초록 | |
| 1-5 | 1-1 에서 목록에 안 뜨면: [IP 주소로 직접 짝 맺기…]에 PC B IP 입력 | 1-2 와 같다 | |

### 마우스·키보드 넘기기 (PC B 가 A 의 오른쪽)

| # | 할 일 | 기대 결과 | 결과 |
|---|---|---|---|
| 1-6 | PC A 마우스를 화면 오른쪽 끝으로 민다 | 커서가 PC B 화면 왼쪽 끝에 나타나고 PC A 커서는 사라진다. A 아이콘이 파랑 | |
| 1-7 | PC B 에서 마우스를 움직이고, 클릭·우클릭·휠·가운데 버튼을 쓴다 | 모두 PC B 에서 동작하고 PC A 에는 아무 일도 없다 | |
| 1-8 | PC B 메모장에 한글·영문 타이핑, 한/영 키, Shift·Ctrl+C/V, Alt+Tab, Win 키 | 모두 PC B 에서 동작한다 | |
| 1-9 | PC B 화면 왼쪽 끝으로 민다 | PC A 로 돌아오고 A 커서가 오른쪽 끝에 다시 보인다 | |
| 1-10 | PC A 화면 오른쪽 위·아래 모서리(10픽셀 안)에 댄다 | 넘어가지 않는다(최대화 창 닫기 버튼 누르기용) | |
| 1-11 | 창 제목 표시줄을 끈 채로 오른쪽 끝에 댄다 | 버튼을 누르고 있는 동안은 넘어가지 않는다 | |
| 1-12 | Scroll Lock 을 누르고 오른쪽 끝에 댄다 | 넘어가지 않는다. 한 번 더 누르면 다시 넘어간다 | |
| 1-13 | PC B 조작 중 Ctrl+Alt+Esc | 곧바로 PC A 로 돌아온다 | |
| 1-14 | PC A 에서 Ctrl+Alt+2, 다시 Ctrl+Alt+1 | PC B 화면 가운데로 갔다가 PC A 로 돌아온다 | |
| 1-15 | PC B 조작 중 PC B 의 실제 마우스를 움직인다 | PC A 는 자기 화면으로 돌아오고 PC B 는 자기 마우스로 쓴다 | |
| 1-16 | PC B 의 실제 마우스로 B 화면 왼쪽 끝을 민다 | PC B 마우스로 PC A 를 조작한다(어느 PC든 주인) | |
| 1-17 | PC B 조작 중 PC A 에서 Shift 를 누른 채 넘어간 뒤 뗀다 | 어느 PC에도 Shift 가 눌린 채 남지 않는다 | |
| 1-18 | PC B 의 작업 관리자(관리자 권한 창) 위에서 클릭·타이핑 | 동작한다 | |
| 1-19 | 트레이 메뉴에서 PC B 를 [내 왼쪽에 두기] | 이제 PC A 왼쪽 끝으로 넘어가고, PC B 쪽 메뉴에는 PC A 가 오른쪽으로 바뀌어 있다 | |
| 1-20 | 모니터 배율(125%, 150%)이 다른 PC 사이에서 1-6 ~ 1-9 | 커서가 튀지 않고 끝까지 닿는다 | |

## 2단계: 클립보드

1단계 짝 맺기가 끝난 두 PC에서 확인한다. 트레이 메뉴 [클립보드 공유]가 양쪽 모두 켜져 있어야 한다(기본 켬).

| # | 할 일 | 기대 결과 | 결과 |
|---|---|---|---|
| 2-1 | PC A 메모장에서 한글·영문·이모지 글을 복사 → PC B 메모장에 붙여넣기 | 같은 글이 붙는다 | |
| 2-2 | PC A 웹 페이지(굵은 글씨·링크 포함)를 복사 → PC B 워드/한글/Outlook 에 붙여넣기 | 서식이 살아 있다 | |
| 2-3 | PC A 에서 Win+Shift+S 로 화면 일부 캡처 → PC B 그림판에 붙여넣기 | 같은 그림이 붙는다 | |
| 2-4 | 투명 배경 PNG 를 이미지 편집기에서 복사 → PC B 에 붙여넣기 | 투명도를 아는 프로그램에서는 투명하게 붙는다 | |
| 2-5 | 아주 큰 이미지(예: 8000×8000) 복사 직후 PC B 로 마우스를 옮긴다 | 마우스는 끊기지 않고, 잠시 뒤 PC B 에 붙여넣을 수 있다 | |
| 2-6 | PC B 에서 복사 → PC A 에 붙여넣기 | 반대 방향도 된다 | |
| 2-7 | 비밀번호 관리자(예: 1Password, Bitwarden, KeePass)에서 비밀번호 복사 | PC B 에 넘어가지 않는다(기록에 "공유 제외 표시" 가 남는다) | |
| 2-8 | 한쪽에서 [클립보드 공유]를 끄고 복사 | 넘어가지 않는다. 다시 켜면 넘어간다 | |
| 2-9 | 탐색기에서 파일을 복사 | 아직 넘어가지 않는다(3단계에서 넣는다) | |

클립보드 읽기·쓰기 자체는 진단 명령으로도 확인할 수 있다. 결과 파일 끝에 `RESULT PASS` 가 나와야 한다. 지금 클립보드 내용은 시험이 끝난 뒤 되돌린다.

```bash
ShareCom.exe --selftest-clipboard result.txt
```
